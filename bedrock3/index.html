A self-building software company

Bedrock

People set the direction. Everything else, it builds itself.

Bedrock writes, reviews, and ships its own software — then rewrites how it does all three. Every service, every agent, every rule is one build graph, including the runner that deploys it. Work arrives only as proposals: sandboxed, reviewed, recorded, and upload-only — nothing merges itself. It climbs, level by level, from a single hand-run seed toward a company that runs itself.

01 / The Flywheel

It generates the data that improves it.

The engineering process emits its own data — every change, dispatch, review, and agent conversation is a logged, provenance-tagged trajectory. That data improves the harness today, and it's the same substrate designed to improve the model tomorrow. A Voyager-style lifelong-learning loop, applied to a whole software company rather than a single agent.

02 / Safe by Construction

Self-modifying, but never unsupervised.

  • Deny-first sandboxing — agents get nothing they aren't explicitly granted
  • Per-agent isolation and identity — every actor is contained and attributable
  • A human gate on the trust base — the root of trust only ever moves by hand
  • An explicitly advisory review judge — an LLM can't be a hard gate on adversarial change, so it never is one
03 / The Climb

From a hand-run seed, level by level.

Level 0 is a seed a human runs by hand. At each level the system earns more autonomy over its own process — auditing its frictions, proposing improvements, and ratcheting them in — without ever removing the human from the trust base. The goal isn't a faster agent; it's a software organization that improves how it improves.
