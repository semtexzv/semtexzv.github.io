03 / AI Projects
Bedrock · Autonomous Software Engineering Platform
semtexzv.github.io/bedrock
A fleet of coding agents that builds, reviews, and ships a software platform end to end · 2026 – Present
  • A control plane for coding agents: a fleet of ≈15 collaborating agents that build, review, and integrate changes into a shared monorepo, end to end
  • Built on Buck2 and jj: a self-integrating monorepo with hermetic builds, CI gating, and a web review front end, so every change an agent makes is reproducible and lands through one pipeline
  • Generates its own data: every change, dispatch, conversation, and review is a logged trajectory. The direction is the platform as an RL environment, with rubric-scored trajectories (rubrics as rewards) and GRPO-style post-training of its own agents on its own data
  • Bounded self-modification, designed against reward hacking: a structural security layer protects the core, changes to it require human approval, and the automated reviewer is advisory, never the sole authority on an adversarial change. Safety is a structural property, not a policy

An agent that extends itself by recompiling its own binary
